# Fase 5 — Guías de Desarrollo paso a paso

> **Cómo funcionan estas guías:** cada una está escrita como un **desarrollador experimentado pensando en voz alta** mientras construye Cartelera. El alumno lee las decisiones (con su porqué, referenciando los documentos de las fases 1–4), **copia y pega los bloques de código**, y verifica al final de cada paso que todo funciona antes de seguir.
>
> **Reglas del alumno:**
> 1. No saltees ninguna ✅ Verificación: es tu prueba de que el paso quedó bien.
> 2. Lee los bloques "🧠 El desarrollador piensa" antes de copiar: entenderás qué estás pegando.
> 3. Si algo falla, el error es información: léelo completo antes de pedir ayuda.
